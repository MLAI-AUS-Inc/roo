# Unblock Studio contributor charts when finance needs review

Proposed on 26 November 2026. An on-demand contributor report should answer “whose hours can we substantiate for this project?” from the work evidence available at the requested cutoff. The report must disclose incomplete coverage. An invoice credit can matter to a balance report without affecting the hours on a contractor's timesheet.

## What the existing PRs cover

- Roo has shipped both charts. The draft follow-up changes cumulative plotting and the Slack waiting notice. At draft revision `f0f4de8`, an offline request for both charts with all three reported gaps remained queued and uploaded zero files. [Chart PR](https://github.com/MLAI-AUS-Inc/roo/pull/340) · [Waiting-notice PR](https://github.com/MLAI-AUS-Inc/roo/pull/341)
- The backend already matches some submitted hours to invoices. Its latest mode permits partial work coverage and unreviewed submissions. A cash allocation failure still withholds the entire signed snapshot. Any nonzero credited amount triggers that failure, even when reconciled cash agrees with the invoice. [Submission reconciliation](https://github.com/MLAI-AUS-Inc/mlai-backend/pull/1335) · [Cash check](https://github.com/MLAI-AUS-Inc/mlai-backend/blob/96f557857c315c3617344cb10a32220b397fb047/integrations/services/studio_report_source.py#L187-L190) · [Snapshot publication](https://github.com/MLAI-AUS-Inc/mlai-backend/blob/96f557857c315c3617344cb10a32220b397fb047/integrations/services/studio_report_source.py#L458-L477)

## Work to deliver

1. **Backend reporting owner — prepare signed hours evidence.** Add a work-only mode to the private prepare endpoint for owners using recorded hours. Dispatch before loading or locking the Xero connection. Reuse the work manifest, submission matching, duplicate and revision checks. Return verified project, builder, quantity, date precision and provenance, together with the review cutoff, latest supported work date, source check time and unresolved work. Bind the mode, owner, organisation, project scope, nonce and original cutoff to the signed response. Unknown work can qualify a subtotal when its omission is identifiable and the remaining rows are trustworthy. A failed required source read, conflicting provenance that could double-count included work, or unverifiable scope must withhold the affected report. A rejected finance candidate is never a source for delivery.
2. **Roo reporting owner — consume that evidence for on-demand contributor charts.** Select the new mode only for the recorded-hours portion of an on-demand hours request with a contributor chart. Validate and freeze it under its own preparation identity. Reuse the supported work allocation and project filters from the recorded-hours path. Use the same rows and precision for the stacked chart, cumulative chart, detail and CSV. Preserve the existing Linear path for task-based projects and label estimates. Show when work was fully reviewed, the date of the latest included entry, and which periods or allocations remain uncertain. An empty selection with incomplete coverage should explain the gap. Keep the existing source requirements for balance and Friday reports. Recheck actor, grants, project scope and frozen evidence at delivery, including detailed follow-ups.
3. **Studio reviewer — publish the work evidence.** Classify outstanding contractor submissions by project and invoice revision in the private review records. Match supported lines to a verified builder, work period and quantity. Record unrelated submissions against the correct scope, and hold mixed-project quantities until a split is evidenced. Preserve source digests and count overlapping timesheets and invoices once. Publish the reviewed file atomically after a validation preview. Advance the owner-wide coverage date only when the reviewer can attest coverage across that owner's projects. A later individual entry can appear in a partial chart while that date stays earlier.
4. **Finance reporting owner — support verified credits in balance reports.** Track the original invoice amount, reconciled cash, verified credit allocations and amount due separately. Match credit evidence to the same contact, invoice, currency and effective cutoff. Reconcile to the cent and handle voids, revisions and full or partial credits. Derive purchased hours from eligible receipts under the existing rules. An unmatched credit, ambiguous cutoff or cash discrepancy stays in finance review. This change can ship independently of contributor charts.
