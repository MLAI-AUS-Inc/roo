# Coworking intents v2 rollout (superseded)

V2 is retained only as migration history for fresh databases. It is not the
current deployment target and must not be run on its own.

Use the [v3 rollout and reconciliation runbook](coworking-intents-v3-rollout.md)
for every current environment. V3 is the append-only successor that repairs
databases which may already have recorded an earlier shared v2 body.
